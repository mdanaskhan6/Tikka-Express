TIKKA EXPRESS — LOCAL FOOD PHOTOS EDITION

This package includes local food-photo assets so menu images do not depend on remote photo URLs.

Files:
- index.html
- style.css
- script.js
- images/food/: hero and dish photos
- images/: SVG artwork fallback assets

Run:
1. Extract the ZIP.
2. Keep the images folder alongside index.html, style.css, and script.js.
3. Open index.html in a browser, or run with VS Code Live Server.

Food photos are included locally and should display offline. Google Fonts may still need an internet connection.
This is a front-end demo only. It does not send real orders or process payments.
